📖 About this project

Wild India Atlas is an open-access interactive biodiversity resource built from verified government census data and live GBIF observations. Every number is sourced, every species fact-checked.

🗺️
What is Wild India Atlas?
An interactive single-page atlas tracking 23 of India's most threatened species across all 36 states and UTs. Select a species card to colour the map by population density, then click any state to pull a live dossier of every animal ever recorded there — powered by over 1 billion GBIF occurrence records.

How is the data sourced?
Every population figure comes from the most recent official government census or published scientific survey. Where a per-state count doesn't exist, states appear as "range" states — no numbers are invented.

How it was built
Sourced & fact-checked 23 species
Cross-referenced NTCA, WII, Gujarat Forest Dept, SPAI, SAIEE and state forest departments for every number
Built the India state map
Downloaded and simplified a GeoJSON of all 36 states with Mapshaper, then wrote a custom planar projection to fix a winding-order bug that was rendering India inside-out
Wired live GBIF API
Each state click queries GBIF's occurrence search API in real-time, returning every animal species georeferenced within the state's bounding box
Full SEO · 24/24 checks
JSON-LD structured data, Open Graph, Twitter meta, canonical, sitemap.xml, robots.txt

Why it matters
India is home to ~7–8% of the world's animal species, with some found nowhere else on Earth. The Asiatic Lion exists in a single forest. The Sangai deer walks on floating reeds in one lake. The Hangul clings to one valley in Kashmir. Making this data visible and accessible is a small act toward keeping these animals in public memory — and in public concern.
